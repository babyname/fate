## FATE v4.3.0

这个版本把 FATE 打磨成一个可以直接交给使用者打开的项目：README 改为面向使用者的入口、补齐真实界面截图、清掉长期堆积的历史构建产物和废弃代码，同时修复了五格半吉计分和「探索更多」返回空值的问题。

### 修复

- **五格半吉计分**：半吉不再被当成「吉」计入 15 分，改为独立的 8 分；凶为 -5 分。总分与名次因此恢复正确。
- **探索更多**：候选池耗尽时 `/api/v1/explore` 返回 `[]` 而不是 `null`，前端不再把它当错误处理。
- **前后端接口对齐**：前端统一走 `/api/v1/*`，`avoid_chars` / `require_chars` 改为后端需要的传参形式。
- **并发安全**：候选表内含读写锁，改为指针别名，消除按值复制锁导致的 `go vet` 告警。
- **发布构建**：数据库驱动是纯 Go 实现，关闭 CGO，修复 `linux/arm64` 交叉编译失败。

### 新增

- 官方同名查询入口（全国 / 江苏 / 山东），可一键复制全名并跳转查询。
- 五格吉凶在表格视图和卡片视图中直接展示。
- 4 张真实 Web UI 截图，`scripts/capture-screenshots.mjs` 可复现生成。

### 清理

- 删除 37 个历史前端 bundle，并开启构建目录自动清空，产物不再累积。
- 删除第二套评分实现、未被引用的包、孤儿命令、重复的静态资源嵌入，以及零调用的方法和类型。
- 下线两个没有后端实现的界面入口（名字打分、诗词检索），避免点击后请求不存在的接口。
- 删除零断言测试，为纯打印用例补上断言。

### 文档与验收

- 中英文 README 重写为使用者入口，开发者内容迁至 `docs/DEVELOPMENT.md`。
- `scripts/verify-release.sh` 与 `scripts/verify-release-assets.sh` 提供可复现验收，真实响应与校验结果落盘 `tests/acceptance/v4.3.0/evidence/`。

| --- | --- |
| Windows x64 | `fate-windows-amd64.zip` |
| macOS Intel | `fate-darwin-amd64.tar.gz` |
| macOS Apple Silicon | `fate-darwin-arm64.tar.gz` |
| Linux x64 | `fate-linux-amd64.tar.gz` |
| Linux ARM64 | `fate-linux-arm64.tar.gz` |
| 数据库包 | `fate-v4.3.0.zip`（解压到程序同目录） |
