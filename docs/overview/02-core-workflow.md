# fate 核心工作流程

## 流程总览

fate 的核心工作流程分为4个阶段：

```
输入阶段 → 计算阶段 → 推荐阶段 → 输出阶段
```

每个阶段都有明确的职责和数据流转。

---

## 第一阶段：输入阶段

### 职责

接收用户的输入参数，进行初步验证和预处理。

### 输入参数

用户需要提供：

| 参数 | 类型 | 必填 | 说明 | 示例 |
|-----|------|------|------|------|
| birthDate | time.Time | ✓ | 出生日期（公历） | 2020-01-23 11:31 |
| gender | int | ✓ | 性别（1男，0女） | 1 |
| isLunar | bool | ✗ | 是否农历日期 | false |
| surname | string | ✗ | 姓氏 | 张 |
| preferences | map | ✗ | 其他偏好（五行偏好等） | {"wuxing": "木"} |

### 验证逻辑

1. **日期验证**：
   - 检查日期是否在有效范围内（1900-2100年）
   - 检查日期格式是否正确
   
2. **性别验证**：
   - 检查性别值是否为 0 或 1
   
3. **农历日期验证**：
   - 如果 isLunar=true，检查农历日期是否有效

### 数据预处理

1. **日期转换**：
   - 如果 isLunar=true，将农历日期转换为公历日期
   
2. **时辰计算**：
   - 根据小时计算时辰（子时、丑时等）
   
3. **参数标准化**：
   - 将输入参数转换为标准格式

### 输出数据

输入阶段输出：

```go
type InputData struct {
    SolarDate   time.Time  // 公历日期（标准化）
    LunarDate   time.Time  // 农历日期（如需要）
    Gender      int        // 性别（标准化）
    Hour        int        // 小时
    TimeBranch  string     // 时辰地支
    Surname     string     // 姓氏
    Preferences map[string]interface{}  // 其他偏好
}
```

## 第二阶段：计算阶段（chronos模块）

### 职责

根据输入数据，计算八字、五行喜忌等核心数据。

### 计算流程

```
InputData → chronos.GetFateData() → FateData
```

### chronos 模块核心计算

#### 1. 八字计算（四柱）

**计算逻辑**：
- 年柱：根据年份计算（考虑立春修正）
- 月柱：根据月份和节气计算
- 日柱：根据日期计算（使用天文算法）
- 时柱：根据时辰计算（考虑早子时/晚子时）

**算法来源**：
- 桥接 lunar-go 库
- 使用天文算法计算节气
- 支持多流派（立春修正、早子时/晚子时）

**输出数据**：
```go
type BaziInfo struct {
    Sizhu      [4]string  // 四柱干支 ["甲子", "乙丑", "丙寅", "丁卯"]
    Wuxing     [4]string  // 五行 ["木水", "木土", "火木", "火木"]
    Nayin      [4]string  // 纳音 ["海中金", "海中金", "炉中火", "炉中火"]
    Shishen    [4]string  // 十神 ["比肩", "劫财", "食神", "伤官"]
    Canggan    [4][]string // 藏干 [["癸"], ["己","辛","癸"], ...]
    Xunkong    [4]string  // 旬空 ["戌亥", "申酉", "午未", "辰巳"]
    Zodiac     string      // 生肖 "鼠"
    Constellation string   // 星座 "水瓶座"
}
```

#### 2. 五行喜忌分析

**计算逻辑**：
- 根据日主（日柱天干）判断日主强弱
- 根据五行生克关系计算喜用五行
- 根据五行生克关系计算忌神五行
- 提供五行补益建议

**算法来源**：
- 自己实现（lunar-go不提供）
- 基于传统命理学理论

**算法步骤**：

1. **日主强弱判断**：
   - 统计四柱中五行数量
   - 判断日主是否得令、得地、得生、得助
   - 综合判断日主强弱（身强、身弱）

2. **喜用五行推导**：
   - 身强：喜克泄耗（食伤、财星、官杀）
   - 身弱：喜生扶（印星、比劫）
   - 根据五行生克关系推导具体五行

3. **忌神五行推导**：
   - 身强：忌生扶（印星、比劫）
   - 身弱：忌克泄耗（食伤、财星、官杀）
   - 根据五行生克关系推导具体五行

4. **五行补益建议**：
   - 根据喜用五行，建议补益的五行
   - 提供具体建议（如名字五行、颜色、方位等）

**输出数据**：
```go
type WuxingXijiInfo struct {
    DayGan       string      // 日主（天干）
    DayWuxing    string      // 日主五行
    XiWuxing     []string    // 喜用五行 ["木", "火"]
    JiWuxing     []string    //忌神五行 ["金", "水"]
    Analysis     string      // 分析说明 "日主身强，喜克泄耗..."
    SuggestWuxing string     // 建议补益五行 "木火"
}
```

#### 3. 大运计算（可选）

**计算逻辑**：
- 根据性别和八字计算大运起运年龄
- 计算大运干支（10年一运）
- 计算流年、流月（可选）

**算法来源**：
- 桥接 lunar-go 库

**输出数据**：
```go
type DayunInfo struct {
    StartAge     []int       // 大运起始年龄 [2, 12, 22, ...]
    Sizhu        []string    // 大运干支 ["甲子", "乙丑", ...]
}
```

### 输出数据

计算阶段输出：

```go
type FateData struct {
    SolarDate  string         // 公历日期 "2020年1月23日 11:31"
    LunarDate  string         // 农历日期 "2019年腊月二十九 午时"
    Gender     int            // 性别 1
    Bazi       *BaziInfo      // 八字信息
    WuxingXiji *WuxingXijiInfo // 五行喜忌信息
    Dayun      *DayunInfo     // 大运信息（可选）
}
```

### 性能优化

1. **一次性计算**：
   - GetFateData() 一次性返回所有数据
   - 减少多次调用的性能开销
   
2. **缓存优化**：
   - 缓存常用计算结果（如节气时刻）
   - 避免重复计算
   
3. **预加载优化**：
   - 预加载 lunar-go 的数据表
   - 减少运行时加载开销

## 第三阶段：推荐阶段（naming模块）

### 职责

根据五行喜忌数据，筛选合适的名字并进行评分推荐。

### 推荐流程

```
FateData → naming.FilterNames() → names → naming.RateNames() → ratedNames
```

### naming 模块核心计算

#### 1. 名字筛选（FilterNames）

**筛选逻辑**：

1. **五行匹配筛选**：
   - 根据喜用五行筛选名字
   - 名字的五行属性必须符合喜用五行
   - 排除忌神五行的名字
   
2. **笔画数筛选**：
   - 根据笔画数范围筛选名字
   - 笔画数符合传统起名规则（如三才五格）
   
3. **音韵筛选**（可选）：
   - 排除不雅读音
   - 符合音韵搭配规则
   
4. **姓氏搭配筛选**：
   - 名字与姓氏搭配合理
   - 避免不好的组合

**筛选规则**：

```go
type FilterRule struct {
    XiWuxing      []string  // 喜用五行 ["木", "火"]
    JiWuxing      []string  //忌神五行 ["金", "水"]
    StrokeRange   [2]int    // 笔画范围 [10, 20]
    AvoidSounds   []string  // 避免读音 ["死", "丧"]
    Surname       string    // 姓氏 "张"
}
```

**筛选结果**：
- 从名字库中筛选出符合规则的候选名字列表
- 每个名字包含：汉字、笔画、五行、读音等信息

#### 2. 名字评分（RateNames）

**评分逻辑**：

综合评分 = 五行评分 × 50% + 笔画评分 × 30% + 音韵评分 × 20%

**五行评分**（权重50%）：
- 名字五行是否符合喜用五行（80分基础）
- 五行搭配是否合理（+10分）
- 五行属性是否清晰（+10分）

**笔画评分**（权重30%）：
- 三才五格评分（基于康熙字典笔画）
- 笔画数是否吉利（+5分）
- 笔画搭配是否合理（+5分）

**音韵评分**（权重20%）：
- 读音是否响亮（+5分）
- 读音是否顺口（+5分）
- 是否有不雅谐音（-10分）

**评分公式**：

```go
score := wuxingScore * 0.5 + strokeScore * 0.3 + soundScore * 0.2
```

**评分结果**：
- 每个名字获得一个综合评分（0-100分）
- 评分越高，名字越合适

#### 3. 名字排序推荐

**排序逻辑**：
- 根据评分从高到低排序
- 推荐评分最高的前N个名字（如前10个）

**推荐结果**：
```go
type RecommendedName struct {
    Name       string     // 名字 "张明轩"
    Strokes    int        // 笔画数 15
    Wuxing     string     // 五行属性 "木火"
    Score      float64    // 综合评分 95.5
    Analysis   string     // 分析说明 "五行符合喜用..."
}
```

### 输出数据

推荐阶段输出：
- 推荐的名字列表（按评分排序）
- 每个名字的详细信息（笔画、五行、评分等）

## 第四阶段：输出阶段（analysis模块）

### 职责

格式化输出八字解析和名字解析，让用户了解推荐的依据。

### 输出流程

```
FateData + ratedNames → analysis.FormatOutput() → formattedOutput
```

### analysis 模块核心输出

#### 1. 八字解析输出

**输出内容**：

1. **基本信息**：
   - 公历日期、农历日期
   - 性别、生肖、星座
   
2. **四柱信息**：
   - 年柱、月柱、日柱、时柱（干支）
   - 五行、纳音
   
3. **十神信息**：
   - 天干十神、地支藏干十神
   
4. **五行喜忌**：
   - 日主、日主五行
   - 喜用五行、忌神五行
   - 五行补益建议
   
5. **其他信息**：
   - 旬空、藏干
   - 大运信息（可选）

**输出格式**：


#### 2. 名字解析输出

**输出内容**：

   - 名字列表（按评分排序）

   - 每个名字的笔画、五行、评分
   
3. **名字分析**：
   - 五行匹配说明

   - 最佳推荐名字

#### 3. 格式化输出（多格式支持）

- 文本格式（Text）：便于阅读

**格式化逻辑**：
- 根据配置选择输出格式
- 使用模板生成格式化输出
- 支持自定义模板

### 输出数据

输出阶段输出：
- 格式化的八字解析文本
- 格式化的名字推荐文本
- 可选的JSON/HTML格式输出

## 关键节点和决策点

### 关键节点

1. **输入验证**：
   - 如果日期无效，返回错误
   - 如果农历日期无效，返回错误
   
2. **八字计算**：
   - 计算成功，继续推荐
   - 计算失败，返回错误
   
3. **五行喜忌分析**：
   - 分析成功，用于筛选名字
   - 分析失败，使用默认规则
   
4. **名字筛选**：
   - 筛选结果不为空，继续评分
   - 筛选结果为空，扩大筛选范围或提示
   
5. **名字评分**：
   - 评分成功，排序推荐
   - 评分失败，使用默认排序

### 决策点

1. **流派选择**：
   - 是否使用立春修正（年柱）
   - 是否使用早子时/晚子时（时柱）
   
2. **筛选规则**：
   - 是否启用笔画筛选
   - 是否启用音韵筛选
   
3. **输出格式**：
   - 文本格式、JSON格式、HTML格式

## 异常处理

### 异常类型

1. **输入异常**：
   - 日期格式错误
   - 日期范围错误
   - 参数缺失
   
2. **计算异常**：
   - lunar-go 计算错误
   - 五行喜忌分析错误
   
3. **推荐异常**：
   - 汉字数据库查询错误
   - 筛选结果为空
   
4. **输出异常**：
   - 格式化错误
   - 模板错误

### 异常处理策略

1. **输入异常**：
   - 返回错误信息，提示用户修正
   
2. **计算异常**：
   - 使用默认值或降级处理
   
3. **推荐异常**：
   - 扩大筛选范围或提示用户调整
   
4. **输出异常**：
   - 使用默认格式或降级输出

---

## 总结

fate 的核心工作流程是一个清晰的4阶段流程：

1. **输入阶段**：验证和预处理用户输入
2. **计算阶段**：chronos 计算八字和五行喜忌
3. **推荐阶段**：naming 筛选和评分名字
4. **输出阶段**：analysis 格式化输出解析

每个阶段都有明确的职责、数据流转和性能目标，确保整个流程高效、准确、可靠。
