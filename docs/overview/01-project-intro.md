# fate 项目介绍

## 项目名称

**fate** - 智能起名软件

---

## 项目定位

fate 是一个基于八字五行喜忌的智能起名工具，通过分析出生日期的八字信息，推算五行喜忌，为用户推荐合适的名字。

**核心特点**：
- 基于传统命理学（八字、五行）
- 结合现代算法（智能推荐、评分）
- 提供完整的解析输出（八字解析、名字解析）

---

## 项目目标

### 主要目标

**为用户提供科学、合理的起名建议**

具体目标：

1. **准确计算八字**：根据出生日期准确计算年柱、月柱、日柱、时柱
2. **科学分析五行喜忌**：基于日主强弱、五行生克关系，推算喜用五行和忌神五行
3. **智能推荐名字**：根据五行喜忌筛选合适的名字，综合评分推荐最佳方案
4. **完整解析输出**：提供八字解析、名字解析，让用户了解推荐的依据

### 目标用户

- **新生儿家长**：为新生儿起名
- **改名咨询者**：需要改名的成年人
- **企业服务**：批量起名服务
- **第三方开发者**：通过 API 调用起名服务

## 技术特点

### 技术栈

| 技术 | 用途 | 说明 |
|-----|------|------|
| Go | 主语言 | 性能好、并发强、编译快 |
| lunar-go | 农历库 | 功能完整的农历计算库 |
| SQLite/MySQL | 数据库 | 存储汉字数据库 |
| YAML/JSON | 配置文件 | 配置参数 |

### 核心算法

1. **八字计算**：
   - 桥接 lunar-go 库
   - 使用天文算法计算节气
   - 支持多流派（立春修正、早子时/晚子时）

2. **五行喜忌分析**：
   - 自己实现（lunar-go 不提供）
   - 基于日主强弱判断
   - 基于五行生克关系计算

3. **名字筛选**：
   - 五行匹配算法
   - 笔画数筛选
   - 音韵筛选（可选）

4. **名字评分**：
   - 五行评分（权重 50%）
   - 笔画评分（权重 30%）
   - 音韵评分（权重 20%，可选）

## 项目背景

### 为什么需要 fate？

**传统起名的痛点**：

1. **缺乏科学依据**：很多起名服务缺乏八字分析，仅凭经验或主观判断
2. **效率低**：人工起名耗时耗力，无法快速筛选大量名字
3. **缺乏解析**：用户不知道推荐依据，缺乏信任
4. **批量需求难满足**：企业批量起名需求难以高效处理

**fate 的解决方案**：

1. **科学计算**：基于八字五行喜忌，提供科学依据
2. **高效推荐**：算法智能筛选，快速推荐最佳名字
3. **完整解析**：提供八字解析和名字解析，用户了解依据
4. **批量支持**：支持批量起名，满足企业需求

## 项目结构

### 模块划分

fate 采用模块化设计，分为以下模块：

| 模块 | 职责 | 说明 |
|-----|------|------|
| chronos | 日历功能 | 提供八字、五行喜忌等数据 |
| naming | 起名功能 | 筛选名字、评分、推荐 |
| analysis | 解析功能 | 输出八字解析、名字解析 |
| config | 配置管理 | 配置参数、数据库配置 |
| cmd | CLI入口 | 命令行接口 |

### 模块关系

```
输入 → chronos → naming → analysis → 输出
       (计算)    (筛选)    (格式化)
```
