# fate 术语表

## 术语总览

本术语表定义 fate 项目中使用的命理术语和项目术语，便于查询和理解。

## 基础术语

### 八字（四柱）

**定义**：
八字，又称四柱，是指一个人出生时的年、月、日、时四个时间点对应的天干地支组合。

**组成**：
- 年柱：出生年份的天干地支
- 月柱：出生月份的天干地支
- 日柱：出生日期的天干地支
- 时柱：出生时辰的天干地支

**示例**：
甲子年、乙丑月、丙寅日、丁卯时 → 八字：甲子乙丑丙寅丁卯

**用途**：
- 用于分析命运、性格、运势等
- 用于起名、择日、婚配等

### 六十甲子

**定义**：
六十甲子是天干和地支按顺序组合形成的六十个组合，用于纪年、纪月、纪日、纪时。

**组合规则**：
天干（10个）和地支（12个）按顺序组合，形成60个组合（10和12的最小公倍数是60）。

**列表（部分）**：
甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸酉、甲戌、乙亥...

**用途**：
- 用于纪年、纪月、纪日、纪时
- 用于纳音计算

## 五行术语

### 五行

**定义**：
五行是中国古代哲学中的五种基本元素：金、木、水、火、土。

**列表**：
金、木、水、火、土

**含义**：
| 五行 | 含义 | 特性 |
|-----|------|------|
| 金 | 金属、坚硬 | 收敛、肃杀 |
| 木 | 植物、生长 | 生发、柔和 |
| 水 | 液体、流动 | 寒凉、向下 |
| 火 | 火焰、热能 | 炎热、向上 |
| 土 | 土壤、承载 | 承载、受纳 |

## 十神术语

### 十神

**定义**：
十神是根据日主（日柱天干）与其他天干、地支藏干的五行关系推导出的十个术语，用于分析命运、性格等。

**列表**：
比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印

---

### 十神详解

| 十神 | 五行关系 | 含义 | 说明 |
|-----|---------|------|------|
| 比肩 | 同五行同阴阳 | 兄弟姐妹、朋友 | 同类相助 |
| 劫财 | 同五行异阴阳 | 竞争、争夺 | 同类相争 |
| 食神 | 我生同阴阳 | 才艺、子女 | 我生出 |
| 伤官 | 我生异阴阳 | 才艺、叛逆 | 我生出 |
| 偏财 | 我克同阴阳 | 偏门财运 | 我克出 |
| 正财 | 我克异阴阳 | 正门财运 | 我克出 |
| 七杀 | 克我同阴阳 | 压力、权威 | 克我入 |
| 正官 | 克我异阴阳 | 官职、权威 | 克我入 |
| 偏印 | 生我同阴阳 | 学业、偏门 | 生我入 |
| 正印 | 生我异阴阳 | 学业、正门 | 生我入 |

**示例**：
日主为丙（火），其他天干：
- 丙（火） → 比肩（同五行同阴阳）
- 丁（火） → 劫财（同五行异阴阳）
-戊（土） → 食神（火生土，同阴阳）
- 己（土） → 伤官（火生土，异阴阳）
- 庚（金） → 偏财（火克金，同阴阳）
- 辛（金） → 正财（火克金，异阴阳）
- 壬（水） → 七杀（水克火，同阴阳）
- 癸（水） → 正官（水克火，异阴阳）
- 甲（木） → 偏印（木生火，同阴阳）
- 乙（木） → 正印（木生火，异阴阳）

### 大运

**定义**：
大运是根据八字计算的10年一运的命运周期，用于分析人生不同阶段的运势。

**计算方法**：
- 根据性别和八字月柱计算起运年龄
- 10年一运，依次推算大运干支

**示例**：
起运年龄2岁，大运：
- 2-11岁：甲子运
- 12-21岁：乙丑运
- 22-31岁：丙寅运
- ...

---

### 流年

**定义**：
流年是指每一年的运势，用于分析当年运势。

**计算方法**：
- 流年干支 = 当年的天干地支
- 结合大运分析当年运势

**示例**：
2024年（甲辰年）的流年干支为甲辰。

---

### 流月

**定义**：
流月是指每一月的运势，用于分析当月运势。

**计算方法**：
- 流月干支 = 当月的天干地支
- 结合大运、流年分析当月运势

## 项目术语

### FateAPI

**定义**：
FateAPI 是 fate 项目提供的核心 API，一次性返回所有数据。

**接口**：
```go
func GetFateData(input *FateInput) (*FateData, error)
```

---

### FateInput

**定义**：
FateInput 是 fate 的输入参数结构体。

**结构**：
```go
type FateInput struct {
    BirthDate time.Time  // 出生日期（公历）
    Gender    int        // 性别（1男，0女）
    IsLunar   bool       // 是否农历日期
}
```

---

### FateData

**定义**：
FateData 是 fate 的输出数据结构体，包含所有计算结果。

**结构**：
```go
type FateData struct {
    SolarDate  string         // 公历日期
    LunarDate  string         // 农历日期
    Gender     int            // 性别
    Bazi       *BaziInfo      // 八字信息
    WuxingXiji *WuxingXijiInfo // 五行喜忌信息
    Dayun      *DayunInfo     // 大运信息
}
```

---

### BaziInfo

**定义**：
BaziInfo 是八字信息结构体，包含八字的完整数据。

**结构**：
```go
type BaziInfo struct {
    Sizhu      [4]string      // 四柱干支
    Wuxing     [4]string      // 五行
    Nayin      [4]string      // 纳音
    Shishen    [4]string      // 十神
    Canggan    [4][]string    // 藏干
    Xunkong    [4]string      // 旬空
    Zodiac     string          // 生肖
    Constellation string       // 星座
}
```

---

### WuxingXijiInfo

**定义**：
WuxingXijiInfo 是五行喜忌信息结构体，包含五行喜忌分析结果。

**结构**：
```go
type WuxingXijiInfo struct {
    DayGan       string      // 日主（天干）
    DayWuxing    string      // 日主五行
    XiWuxing     []string    // 喜用五行
    JiWuxing     []string    //忌神五行
    Analysis     string      // 分析说明
    SuggestWuxing string     // 建议补益五行
}
```

---

### DayunInfo

**定义**：
DayunInfo 是大运信息结构体，包含大运数据。

**结构**：
```go
type DayunInfo struct {
    StartAge     []int       // 大运起始年龄
    Sizhu        []string    // 大运干支
}
```
