# Screenshots

## Required Screenshots

| File | Content |
|------|---------|
| `home.png` | Home page with input form (surname, birth date, gender, poetry mode) |
| `results.png` | Results page showing top recommended names |
| `table.png` | Candidate table view with pagination |
| `cards.png` | Card view of candidates |

## How to Capture

1. Start the server: `go run ./cmd/server`
2. Open `http://localhost:18080` in your browser
3. Fill in the form: surname=张, birth=2024/06/15 10:30, gender=boy
4. Click "开始命名"
5. Wait for generation to complete
6. Take screenshots of each view
7. Save as PNG files in this directory
